# T5 · Frontend: Katalogverwaltung

---

## Kontext

T4 hat die Buchsuche und die Übernahme in den Katalog implementiert. Bücher können seitdem über die API gespeichert werden, aber es gibt noch keine Möglichkeit, den Kataloginhalt im Browser einzusehen oder Einträge zu entfernen. T5 schließt diese Lücke mit einer zweiten Seite: `manage.html`.

Die Verwaltungsseite ist bewusst einfach gehalten – keine Sortierung, keine Filter, kein Paging. Sie zeigt alle gespeicherten Bücher in einer Tabelle und erlaubt das einzelne Entfernen. Das deckt den vollständigen Verwaltungszyklus für v1 ab.

### Was bereits vorhanden ist

**CSS:** `catalog.css` (aus T4) enthält bereits alle benötigten Klassen für die Verwaltungsseite:

| Klasse | Zweck |
|--------|-------|
| `.catalog-table` | Tabellenstruktur (volle Breite, kollabierte Border) |
| `.catalog-table th / td` | Spalten-Styling (Padding, Border-Bottom) |
| `.catalog-table .cover-thumb` | 40×56px Cover-Thumbnail in der Tabelle |
| `.delete-button` | Rot umrandeter Button, Hover füllt rot |
| `.table-wrapper` | Außen-Padding für die Tabelle |
| `.section-header` | Abschnittsüberschrift über der Tabelle |
| `.status-message` | Zentrale Statusanzeige (Laden / leer / Fehler) |
| `.nav-link` / `.nav-link.active` | Navigation (gleich wie in search.html) |
| `.hidden` | Hilfklasse zum Verstecken |

**Kein CSS-Änderungsbedarf.** `catalog.css` wird nur eingebunden, nicht verändert.

**API-Endpunkte (aus T3):**

### Ziel

Eine eigenständige HTML-Seite `manage.html` mit zugehöriger `manage.js`. Beim Öffnen wird die Katalogliste automatisch geladen. Jeder Eintrag hat einen „Entfernen"-Button. Nach dem Löschen aktualisiert sich die Liste.

## Aufgabe

### 1. `manage.html` – Seitenstruktur

Neue Datei in `static/catalog/`. Bindet `catalog.css` und `manage.js` ein. Gleiche Basis-Struktur wie `search.html` (Container, Header, Nav), aber mit „Mein Katalog" als aktiver Nav-Link.

```html
<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mein Katalog – Library Catalog</title>
  <link rel="stylesheet" href="catalog.css">
</head>
<body>
<div class="container">

  <h1>Library System Catalog</h1>

  <nav class="nav-bar">
    <a href="search.html" class="nav-link">Buchsuche</a>
    <a href="manage.html" class="nav-link active">Mein Katalog</a>
  </nav>

  <!-- Statuszeile (Laden / Fehler / leer) -->
  <div id="statusMsg" class="status-message hidden"></div>

  <!-- Tabellenbereich -->
  <div id="tableContainer" class="table-wrapper hidden">
    <p class="section-header">Bücher im Katalog</p>
    <table class="catalog-table">
      <thead>
        <tr>
          <th>Cover</th>
          <th>Titel</th>
          <th>Autor</th>
          <th>ISBN</th>
          <th>Aufgenommen</th>
          <th></th>
        </tr>
      </thead>
      <tbody id="catalogTableBody"></tbody>
    </table>
  </div>

</div>
<script src="manage.js"></script>
</body>
</html>
```

**IDs als Kontrakt zwischen HTML und JS** (nicht umbenennen):

| ID | Element | Zweck |
|----|---------|-------|
| `statusMsg` | `<div>` | Statusanzeige (Laden, leer, Fehler) |
| `tableContainer` | `<div>` | Wrapper um die Tabelle (bei leerem Katalog hidden) |
| `catalogTableBody` | `<tbody>` | Hier werden die Tabellenzeilen eingefügt |

### 2. `manage.js` – Seitenlogik

Neue Datei in `static/catalog/`. Kein Framework, keine Abhängigkeiten. Gleiche Konventionen wie `search.js` (relativer `API_BASE`, `escapeHtml`-Funktion).

**Konstante und Initialisierung:**
```js
const API_BASE = '';

document.addEventListener('DOMContentLoaded', () => {
    loadCatalog();
});
```

**`loadCatalog()`** – Katalog beim Seitenstart laden:
1. `statusMsg` mit „Katalog wird geladen …" anzeigen, `tableContainer` verstecken
2. `fetch('/catalog/books')` aufrufen
3. Bei Erfolg und nicht-leerem Array:
   - `statusMsg` verstecken
   - `tableContainer` sichtbar machen
   - `renderTable(books)` aufrufen
4. Bei Erfolg und leerem Array:
   - `statusMsg` anzeigen mit: „Noch keine Bücher im Katalog. " + Link zu `search.html` mit Text „Zur Buchsuche →"
   - `tableContainer` versteckt lassen
5. Bei Netzwerkfehler → `statusMsg` mit Fehlermeldung

**`renderTable(books)`** – Tabellenzeilen aufbauen:
- `catalogTableBody` leeren
- Pro Buch eine `<tr>` erzeugen mit:
  - **Cover-Zelle:** `<img class="cover-thumb" src="..." onerror="this.style.visibility='hidden'">` – bei null/leer: `src=""` und Bild sofort verstecken
  - **Titel-Zelle:** `book.title`
  - **Autor-Zelle:** `book.author ?? '–'`
  - **ISBN-Zelle:** `book.isbn ?? '–'`
  - **Datum-Zelle:** `formatDate(book.addedAt)`
  - **Aktions-Zelle:** `<button class="delete-button" data-id="{id}" data-title="{title}">Entfernen</button>`
- Click-Handler auf jeden Delete-Button: `removeBook(id, title)` aufrufen

**`removeBook(id, title)`** – Buch entfernen:
1. Browser-nativen `confirm()`-Dialog anzeigen: `Buch »{titel}« wirklich entfernen?`
2. Bei Ablehnung → nichts tun
3. `DELETE /catalog/books/{id}` aufrufen
4. Bei `204`: `loadCatalog()` erneut aufrufen (vollständige Neuladung der Liste)
5. Bei Fehler: `statusMsg` mit Fehlermeldung anzeigen (Tabelle bleibt sichtbar)

**`formatDate(isoString)`** – Datum formatieren:
- `new Date(isoString).toLocaleDateString('de-DE', { day: '2-digit', month: '2-digit', year: 'numeric' })`
- Beispiel: `"2026-06-04T10:23:41.123Z"` → `"04.06.2026"`
- Fallback bei null/undefined: `'–'`

**`escapeHtml(str)`** – identisch zu `search.js`:
```js
function escapeHtml(str) {
    const div = document.createElement('div');
    div.textContent = String(str);
    return div.innerHTML;
}
```

**`escapeAttr(str)`** – identisch zu `search.js`, für `src`- und `data-`-Attribute.

## Akzeptanzkriterien

- [ ] `manage.html` und `manage.js` liegen unter `src/main/resources/static/catalog/`.
- [ ] `http://localhost:8080/catalog/manage.html` lädt ohne Fehler und ohne JS-Fehler in der Browser-Konsole.
- [ ] Beim Öffnen der Seite wird automatisch `GET /catalog/books` aufgerufen; die Bücherliste erscheint ohne manuelle Aktion.
- [ ] Jedes Buch erscheint als Tabellenzeile mit Cover-Thumbnail, Titel, Autor, ISBN, formatiertem Datum und „Entfernen"-Button.
- [ ] Bücher ohne Cover zeigen kein kaputtes Bild-Icon (leere Zelle oder graue Fläche).
- [ ] Klick auf „Entfernen" öffnet einen Bestätigungsdialog mit Buchtitel; bei Abbruch bleibt der Eintrag erhalten.
- [ ] Nach Bestätigung wird `DELETE /catalog/books/{id}` aufgerufen; die Tabelle aktualisiert sich danach automatisch.
- [ ] Ein leerer Katalog zeigt die Meldung „Noch keine Bücher im Katalog." mit einem funktionierenden Link zur Buchsuche.
- [ ] Das Datum in der Spalte „Aufgenommen" wird im deutschen Format angezeigt (z. B. `04.06.2026`).
- [ ] Navigation: „Mein Katalog" ist als aktiver Link markiert; „Buchsuche" verlinkt zurück auf `search.html`.
- [ ] `catalog.css` wurde nicht verändert.
- [ ] Die bestehenden Seiten `search.html` und `/demo/demo.html` funktionieren weiterhin unverändert.
